# Lab-feedback revision — 25 October 2026

This release restructures the README using the supplied lab draft, publishes English and Chinese manuals, adds credits/contact information, adopts MIT for project software/documentation with separate scientific-data terms, and makes `public/<language>/<language>/` the active UI source for Pages and local gateways.

The single-port Docker dispatcher now offers `/en/` and `/zh/` browser interfaces as well as the existing prediction, result and protected-download API. Port 7860 remains loopback-bound in Compose. Programmatic ModelScope access still requires its platform credential; public visitors use Pages.

`bicycluswingatlas.pages.dev` is a lightweight project navigation entry, not a merger or replacement of the two edition sites. Keeping the edition URLs preserves old share links and browser-specific histories. The entry holds no ModelScope secret or original scientific data.

The 12-gene, 291-image, 72-group scientific release is unchanged. HH stage 0.5 and 0.75 maps are pending biological review. Four newly supplied staining photographs are qualitative visual guides only and have not been registered, quantified, added as source images, or used to paint synthetic fluorescence into the atlas.

GitHub Actions performs publication and post-deployment display/download checks. Actual deployment revisions and live functional acceptance are recorded in the task's detailed modification report and machine-readable acceptance files, rather than inferred from a running build alone.
